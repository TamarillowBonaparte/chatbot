# MedReyGen - Website Aplication
Ini gambar nantinya

MedReyGen adalah aplikasi yang berfokus pada pendeteksi penyakit pernapasan seperti pneumonia, tuberkulosis (TBC), dan COVID-19 melalui citra gambar x-ray. Meskipun data rontgen (x-ray) sering kali telah tersedia, proses diagnosis tetap membutuhkan waktu dan keahlian khusus yang tidak selalu mudah diakses oleh semua kalangan. Berdasarkan kondisi tersebut, kelompok kami mengembangkan sebuah aplikasi berbasis web yang memanfaatkan kecerdasan buatan untuk membantu proses deteksi dini penyakit pernapasan secara otomatis dan efisien.

# Features
Features of this Web app:
* Deteksi penyakit melalui gambar x-ray
* Chatbot dengan Vertex AI
